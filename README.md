# Open String Tuner

A free guitar and ukulele tuner that runs in the phone browser. No ads, no account, nothing to buy, and audio never leaves the device.

- Guitar (E A D G B E), ukulele (G C E A) and chromatic modes
- Needle in cents, plain "tune up / tune down" guidance, green when in tune
- Tap a string to hear its reference tone
- Adjustable A4 reference (430 to 450 Hz)
- Installable to the home screen and works offline after the first visit

Pitch detection uses the McLeod normalised square difference method on the raw microphone signal, in a single HTML file with no dependencies.

## Run it

Open `index.html` over HTTPS (or localhost). Browsers only allow microphone access on secure pages.
